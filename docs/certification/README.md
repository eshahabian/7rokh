## تبدیل به PDF

1. فایل Markdown را در VS Code / Word / Google Docs / Typora باز کنید.
2. نمودارهای Mermaid را در خروجی PDF حفظ کنید (Typora، Obsidian، یا [mermaid.live](https://mermaid.live) → تصویر).
3. برای راهنمای کاربری، تصاویر پوشهٔ `screenshots/` را پر کنید و در سند جایگذاری کنید.
4. حجم نهایی هر PDF را زیر **۵ مگابایت** نگه دارید (تصاویر را فشرده کنید).

# چک‌لیست اقرارنامه (Affidavit)

مستند اقرارنامه را **از خود سامانه گواهی** دانلود و تکمیل کنید. این فایل جایگزین فرم رسمی نیست؛ فقط برای جلوگیری از خطای رایج است.

## نکات الزامی راهنمای سامانه

- حتماً اقرارنامهٔ مربوط به **همان نوع گواهی** انتخاب‌شده را پر و ارسال کنید (فرم اشتباه = ریسک رد درخواست).
- مشخصات نرم‌افزار در اقرارنامه با سایر مدارک یکسان باشد.

## هم‌ترازی پیشنهادی با مدارک این پکیج

| فیلد رایج اقرارنامه | مقدار پیشنهادی برای این محصول |
|----------------------|--------------------------------|
| نام نرم‌افزار | پورتال کستینگ ۷ رخ |
| نام برند / محصول | ۷ رخ |
| نوع نرم‌افزار | تحت وب |
| آدرس دسترسی | `https://7rokh.com/casting-portal/` |
| شرح کوتاه | سامانه معرفی هنرمند و مدیریت فراخوان کستینگ برای کارگردان و تهیه‌کننده |
| مالک / متقاضی | مطابق اطلاعات حقوقی ثبت‌شده در سامانه گواهی |
| نسخه | نسخه‌ای که واقعاً برای ارزیابی در دسترس است |

## کنترل نهایی قبل از ارسال

- [ ] نوع گواهی روی فرم با نوع درخواست یکی است
- [ ] نام نرم‌افزار در اقرارنامه = نیازمندی‌ها = معماری = راهنمای کاربری
- [ ] تاریخ و امضا/مهر مطابق دستورالعمل سامانه تکمیل شده
- [ ] فایل خروجی **PDF** و حجم ≤ ۵ مگابایت است
- [ ] بقیه مدارک الزامی هم PDF و زیر ۵ مگابایت هستند

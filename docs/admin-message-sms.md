# اعلان پیام جدید مدیران با پیامک

پس از ثبت موفق پیام متنی یا عکس در پیام‌رسان، یا پاسخ تماس با ما، اگر نام
کاربری فرستنده `eshahabian` یا `ardavan` باشد، برای موبایل اصلی گیرنده
(`casting_mobile`) اعلان ارسال می‌شود. تطبیق نام کاربری به بزرگی حروف حساس نیست.
متن خصوصی پیام و لینک در پیامک درج نمی‌شود؛ فقط اعلان و راهنمای ورود به حساب درج می‌شود.
برای هر ارسال موفق جدید یک اعلان ارسال می‌شود، حتی اگر کاربر آنلاین باشد.

پیام‌های قدیمی و همگام‌سازی سوابق از مسیر `casting_dm_insert_raw` اعلان ندارند.
مهمان‌های تماس با ما که حساب کاربری و موبایل ثبت‌شده ندارند، پاسخ ایمیلی قبلی
را دریافت می‌کنند. شماره نامعتبر، تنظیم نبودن درگاه یا غیرفعال بودن پیامک باعث
رد شدن اعلان می‌شود. شکست درگاه، ثبت پیام را ناموفق نمی‌کند؛ خطای کلی بدون
شماره موبایل، متن گفتگو یا اطلاعات درگاه در لاگ PHP ثبت می‌شود.

## انتشار روی هاست موجود

فایل‌های زیر با حفظ سایر تنظیمات و تغییرات سرور منتشر شوند:

- `includes/admin-message-sms.php` (فایل جدید؛ پیش از فایل‌های وابسته آپلود شود)
- `includes/chat.php`
- `includes/contact-messages.php`

از همان تنظیمات و اعتبار سامانه پیامک فعلی استفاده می‌شود. کلید جدیدی لازم نیست.
گزینه `CASTING_ADMIN_MESSAGE_SMS_ENABLED` به صورت پیش‌فرض فعال است؛ برای خاموش
کردن اعلان‌ها، در `config.local.php` این مقدار را تعریف کنید:

```php
define('CASTING_ADMIN_MESSAGE_SMS_ENABLED', false);
```

## بررسی

```text
php tests/admin-message-sms.php
```

این تست مستقل از وردپرس، پایگاه داده و پیامک واقعی اجرا می‌شود و ثبت موفق،
شکست ذخیره‌سازی، مدیر مجاز/غیرمجاز، موبایل نامعتبر، مهمان و شکست درگاه را بررسی
می‌کند. پس از انتشار، برای بررسی تحویل واقعی، یک پیام از مدیر به حساب آزمایشی
دارای موبایل ثبت‌شده ارسال و گزارش درگاه پیامک بررسی شود.
